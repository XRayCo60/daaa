# OSTFRONT — جبههٔ شرق

نبرد زندهٔ یک‌نفره / دونفره. فقط دو قدرت: **ورماخت** و **ارتش سرخ**. اروپا سقوط کرده.

## اجرا

```bash
npm install
npm start
```

سپس نشانی سرور را باز کنید (پیش‌فرض `http://localhost:8080`).

## بازی

- **تک‌نفره:** جبهه را انتخاب کنید. ستاد کل، طرف دیگر را می‌راند.
- **دونفره:** یک نفر دونفره را می‌زند. نفر دوم **همان نشانی** را باز می‌کند و مستقیم به انتخاب جبهه می‌آید.

پیروزی با سقوط **برلین** یا **مسکو**.

## کنترل

| کار | کلید |
|---|---|
| انتخاب | چپ‌کلیک / کشیدن جعبه |
| حرکت / حمله | راست‌کلیک |
| تولید | کلیک روی شهر خودی |
| نقطهٔ تجمع | شهر انتخاب → راست‌کلیک روی نقشه |
| نقشه | WASD یا لبهٔ صفحه / اسکرول زوم |

آلمان نفت کم دارد و باید سریع بزند. شوروی عمق، صنعت و **باکو** دارد. یگانِ دور از شهر خودی **بی‌تدارکات** می‌شود (کندتر و ضعیف‌تر).
