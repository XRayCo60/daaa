# daaa — معماری مغز مصنوعی (Neural Circuit Simulator)

> "بیرون از دایره فکر کن" — این یک شبکه عصبی کلاسیک نیست. نورون‌ها دستی چیده می‌شوند، ورودی/خروجی دستی سیم‌کشی می‌شود، و مدل یک گراف نامنظم از توابع ریاضی است که همیشه روشن است.

## ایده انقلابی در یک نگاه
- مدل از صفر و فقط از تجربه مستقیم (درد/پاداش) زبان را کشف می‌کند، نه از دیتاست عظیم.
- هر نورون حداکثر ۲۰ مسیر خروجی دارد، ۱۸ تای شناخته شده و ۲ تای مخفی (motor babbling).
- هر نمونه مدل یک موجودیت منحصربه‌فرد و غیرقابل‌تکثیر است (رفتار در ساختار گراف ثبت می‌شود).
- فایل مدل `.afu` خودکفا است و رانر جداست.

## ساختار پروژه
```
include/  - هدرها: neuron, brain, mana, codec, afu, device, regions
src/      - پیاده‌سازی C++17 (بدون نیاز به AVX2، سازگار با i7-2670QM)
examples/ - تست‌ها
docs/ARCHITECTURE.md - معماری فنی فارسی
afu_runner - برنامه رانر (CLI)
afu_tests  - تست‌های واحد
```

## نیازهای سند اصلی (۷ بند) و پوشش

1. **فایل afu و برنامه ران جدا**: `include/afu.h` فرمت باینری خودکفا (magic `AFU1`, version, CRC)، `src/afu.cpp` ذخیره/بار، `src/runner.cpp` رانر جدا.
2. **تنظیمات CPU، دیدن خروجی، خوراندن خروجی**: رانر دستورات `cpu <percent>`, `output`, `input <متن فارسی>` دارد.
3. **سقف و کف برای سرعت متغیر**: `tps <min> <max>` — حداقل ۱۰ تیک بر ثانیه طبق درخواست، هر تیک = ۱ واحد زمان مدل، پس زمان مدل ۱۰ برابر سریع‌تر می‌گذرد.
4. **سیستم CUDA حتی روی سخت‌افزار ضعیف**: اینترفیس `IDevice` با `CpuDevice` (همیشه فعال) و `CudaDeviceStub` که روی Intel HD 3000 dormant است ولی کامل است؛ روی سیستم قوی (GTX 1050/T4) بدون تغییر کد فعال می‌شود. توضیح: CUDA فقط NVIDIA است، پس روی i7-2670QM با Intel HD 3000 هرگز فعال نمی‌شود — عمداً dormant طراحی شد.
5. **انتخاب بخش و گفتن "این معناداره"**: مفهوم Region (Input, Processing, Output, Memory, Efference) + فلگ `meaningful` + دستور `region mark`.
6. **تابع ورودی خارجی به 0/1 دقیقاً معکوس الگو به حرف فارسی**: کدک `PersianCodec` یک bijection واقعی است: `decode(encode(c))==c` و `encode(decode(p))==p`. تست در `codec_test`.
7. **چند بخش و ورودی نوشتنی**: نورون‌های `InputRegion` با فلگ `external_writable` — برنامه می‌تواند به بخشی از مسیر ورودی‌شان چیزی بنویسد.

## کدک برگشت‌پذیر (هسته جذاب ایده)

- الفبا ۶۴ کاراکتر (۶ بیت): ۳۲ حرف فارسی + فاصله + علائم + رزرو.
- هر حرف = الگوی ۶ بیتی یکتا.
- ورودی خارجی: متن فارسی → `externalInputToBits` → جریان ۰/۱ → تزریق به `InputRegion`.
- خروجی: فایرینگ `OutputRegion` → الگوی ۶ بیتی → `bitsToPersian` → حرف فارسی.
- این دو تابع دقیقاً معکوس هم هستند. در `src/codec.cpp` اثبات ریاضی با `verifyBijection()`.

## مدل نورون

انتخاب نهایی **Izhikevich** (۴ پارامتر، ۲ متغیر، ارزان مثل LIF، متنوع مثل Hodgkin-Huxley):
```
v' = 0.04v² + 5v + 140 - u + I
u' = a(bv - u)
if v≥30: v=c, u+=d
```
- هزینه اسپایک: مانا.
- در تشنج: اسپم بدون مانا ولی سوزاندن `integrity` مسیرها.
- خودجوش (spontaneous firing): `spontaneous_rate`.

## سیستم مانا

- `blood` استخر مشترک (وقتی کلمه معنادار تولید شد تزریق).
- P2P هدیه مستقیم.
- تزریق بیرونی از رانر.
- نورون مبدا را نمی‌فهمد (یادگیری علی از تجربه).
- جوانه‌زنی: اگر mana>آستانه، فرزند می‌سازد با هزینه.

## سرعت: ۱۰ تیک بر ثانیه حداقل

بنچمارک روی Xeon 2.6GHz (سریع‌تر از i7-2670QM):
- ۲۵۶ نورون: ~۴۶k TPS
- ۱k: ~۱۶k TPS
- ۱۰k: ~۱۵۶۰ TPS
- ۵۰k: ~۱۷۶ TPS

روی i7-2670QM واقعی تقریباً ۳-۴ برابر کندتر، باز هم تا ~۱۰k نورون بالای ۱۰ TPS می‌مانیم. برای ۱۰۰k باید بهینه‌سازی batch و احتمالاً CUDA.

- `cpu_percent`: بودجه CPU (مثلاً ۳۰٪ یعنی در هر ثانیه فقط ۳۰۰ms محاسبه).
- `tps_min/max`: سقف و کف.

## بیلد و اجرا

```bash
make -j2
./afu_tests
./afu_runner

# داخل رانر:
> codec_test
> tick 100
> status
> input سلام دنیا
> run 1000
> save model.afu
> quit
```

برای سازگاری با i7-2670QM بدون AVX2:
```bash
CXXFLAGS="-march=sandybridge -O2" make
```

## فاز VM (آینده)

فلگ `vm_mode`:
- false → خروجی فارسی
- true → خروجی به ترمینال VM (فعلاً شبیه‌سازی، بعداً pipe)

معیار پاداش یکسان: اجرای موفق کد = کلمه معنادار = تزریق مانا؛ خطا = نویز = تنبیه.
