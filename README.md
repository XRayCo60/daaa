# OSTFRONT — جبههٔ شرق

نبرد زنده. فقط ورماخت و ارتش سرخ. **Node لازم نیست.**

## تک‌نفره

فایل **`بازی.bat`** را دابل‌کلیک کنید  
یا `public\index.html` را با مرورگر باز کنید.

## دونفره (دو لپ‌تاپ، یک شبکه)

۱. روی **`دونفره.ps1`** راست‌کلیک → **Run with PowerShell**  
۲. مرورگر روی `http://localhost:8080` باز می‌شود.  
۳. نفر دوم همان نشانی LAN را که پنجره نشان می‌دهد باز کند (مثلاً `http://192.168.1.12:8080`).

اگر پاورشل اسکریپت را بست، یک‌بار این را بزنید:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```
