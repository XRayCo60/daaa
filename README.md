# OSTFRONT — جبههٔ شرق

نبرد زنده. فقط ورماخت و ارتش سرخ. **Node لازم نیست.**

## تک‌نفره

فایل **`play.bat`** را دابل‌کلیک کنید  
یا `public\index.html` را با مرورگر باز کنید.

## دونفره (دو لپ‌تاپ، یک شبکه)

۱. روی **`دونفره.ps1`** راست‌کلیک → **Run with PowerShell**  
۲. مرورگر روی `http://localhost:41917` باز می‌شود.  
۳. نفر دوم همان نشانی LAN را که پنجره نشان می‌دهد باز کند (مثلاً `http://192.168.1.12:41917`).

اگر پاورشل اسکریپت را بست، یک‌بار این را بزنید:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

## بازی

پیروزی با سقوط برلین یا مسکو، یا ۲۴ امتیاز. رودخانه را از شهر (پل) رد کن؛ زمستان یخ می‌بندد. راه‌آهن زنده سریع است.

| کار | |
|---|---|
| انتخاب | چپ‌کلیک / جعبه |
| حرکت / حمله | راست‌کلیک |
| تولید | کلیک روی شهر خودی |
| نقشه | WASD / لبهٔ صفحه / اسکرول |
